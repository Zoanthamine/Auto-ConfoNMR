# V2.1维护说明

V2.1在V1.2多样品接口基础上加入快速/严谨构象、J与ECD模块，保留各模块独立计算条件。

## 运行保护

01先检查队列再同步配置，提交互斥与底层台账防止重提；03检查模式只读配置。NMR、J和ECD导出核对阶段输入输出签名。长J工作表名称使用摘要后缀，进度收集兼容正在写入的记录，非有限温度/压力在预检阶段拒绝。

## 迁移支持

辅助资源沿用V1.2公开版本。Sobtop命令路径写入项目副本，XTBPATH由随附share/xtb设置，完整资源目录不重复复制进每个workflow。Gaussian、ORCA等外部安装和站点队列需自行配置。

程序测试及真实任务覆盖见[验证记录](VALIDATION_V2.md)，使用步骤见[README](../README.md)。
